# صدای فارسی رزم‌آور

۵۳ فایل MP3 از متن‌های اصلی `dialogues.mjs` با مدل فارسی Amir در Piper تولید شده‌اند. فایل‌ها تک‌کاناله با نرخ ۶۴ کیلوبیت و بلندی صدای یکسان‌اند. بازی فایل‌های آماده را به‌صورت آفلاین پخش می‌کند؛ ابزار یا مدل تولید به همراه بازی توزیع نمی‌شود.

Voice model: https://huggingface.co/rhasspy/piper-voices/tree/main/fa/fa_IR/amir/medium
Model card: https://huggingface.co/rhasspy/piper-voices/blob/main/fa/fa_IR/amir/medium/MODEL_CARD
Dataset license reported by model card: CC0.
Generator: Piper 1.8.0 (https://github.com/OHF-Voice/piper1-gpl), used as a separate build tool.

The scripts and ONNX model used for synthesis lived in temporary storage. Runtime uses the bundled MP3 recordings only.
